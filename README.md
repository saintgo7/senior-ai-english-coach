# Senior AI English Coach

Senior-friendly AI English conversation PWA MVP.

## Commands

- `npm run dev`: start local development server.
- `npm test`: run unit and component tests.
- `npm run build`: type-check and build production assets.

## AI Mode

The current MVP runs with a mock AI coach by default. Real provider integration should be added behind a server endpoint such as `/api/coach/practice-turn`; do not place provider API keys in browser code.
